# DC ReadMe Infinite

> Automating the upload of a README that does not exist.

A completely unnecessary Discord Rich Presence project that
simulates the infinite upload of a fictional `README.txt`.

## What does it do?

It displays something along the lines of:

Uploading README.txt about user...
[#################--------] 67%

The progress changes periodically.
It may go backwards.
It may corrupt itself.
It will never finish.
This is intentional.

## Why?

I didn't want to manually update my Discord bio.
This was somehow the easier option.

## Current status

⚠️ Under construction.

The code currently contains significantly more infrastructure
than the problem could ever reasonably justify.

## Planned features

- Persistent upload progress

- Fake corruption/recovery events
- Discord Rich Presence integration
- Absolutely no useful functionality
